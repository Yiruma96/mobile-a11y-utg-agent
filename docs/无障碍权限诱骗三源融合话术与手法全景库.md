## 二、无障碍诱骗隐蔽度五级分层体系（Level 0 → Level 4）

结合动态实测核心发现——**良性应用（`38` 款）跳无障碍前应用内说明文本中位数高达 `797 字符`（均值 `893.7 字符`）且 `0/38` 冷启动第一步裸跳；而恶意应用（`88` 款）中位数仅 `79 字符`（均值 `128.8 字符`），`40/88` 竟然为 0 字符裸跳或跨通道隐蔽强推，`46/88` 伴随通知横幅压栈**——我们将全谱系无障碍诱骗严谨划分为 **5 个隐蔽度层级**：

| 分级 | 名称与特征 | 来源覆盖 | 当前实测 / 情报计数 | 代表案例与关键信号 | 鸿蒙纯 UTG + 上下文检测关键点 |
|---|---|---|---:|---|---|
| **Level 0 · 裸跳零话术直拉型** | 应用内 0 字符前置说明，冷启动首步直接 `ACTION_ACCESSIBILITY_SETTI… | 动态 + 静态 | 17 | `Anubis`、`BlackRock`、`AbereBot`、`Oscorp`、`Hqwar`、`Banker` | **0 步前置冷启动直跳** + 服务名品牌仿冒 + 服务描述为空或极短 |
| **Level 1 · 单步显性借口弹窗型** | 以原生 AlertDialog / 极简提示页直白谎称「系统版本兼容 / 视频优化 / 必须开启… | 动态 + 静态 | 19 | `Cerberus`、`Lucy`、`TOASTAMIGO`、`Exobot`、`StealJob`、`basbanke` | 显性借口弹窗 + **单键无取消** + 拒权后重弹同一诱导对话框 |
| **Level 2 · 高仿系统/品牌分步图文引导型** | 通过 WebView / 截图 / 伪造系统设置页高仿银行安全更新、Play Protect、C… | 动态 + 静态 + 情报 | 19 动态 + 3 情报 | `Hydra`、`Coper`、`TeaBot`、`Ermac`、`BingoMod`、`BRATA`、`Brokewell`、`SecuriDropper` | 高仿系统设置/银行更新 WebView + 菜单路径词 + **应用信息→受限设置→无障碍**跨页链 |

| **Level 4 · 带外通话社工 + 伪会议/远控协同型** | 恐吓话术完全发生在电话/语音带外信道（如「百万保障扣费/征信受损」），App 界面极简甚至使用合… | 公开威胁情报（补盲） | 4 典型实战案例 | **「银联会议」「中银会议」「抖音会议」**、正规远控滥用（向日葵/ToDesk）、`Vultur`(电话+假 McAfee) | **通话/VoIP 并发态 + 侧载权威品牌会议名 + 屏幕共享与无障碍三联权限组合**（对合法远控采场景强警示而非误杀） |
