## 分析结论（定向核验）

**1. 无障碍服务声明本身是明牌的“Google Chrome”**
- Manifest 中的 [无障碍服务声明](<resource-unit:#1 manifest:components>) 只标注了 `com.travelabout8.p040l`、`BIND_ACCESSIBILITY_SERVICE` 和 `android.accessibilityservice.AccessibilityService` 三个声明要素；其中 `android:label` 指向 `@string/a`，而 [res/values/strings.xml](<resource-unit:#1 file:res/values/strings.xml#L3>) 把这个字符串写成了 **`Google Chrome`**。
- 同一个 strings.xml 还定义了 `gTtUEj` = **`Habilite esta opción para proteger totalmente su dispositivo móvil`**（西班牙语，意为“启用此选项以完全保护您的移动设备”）。这句说明用西语恐吓和“完全保护”话术伪装安全诉求，正是无障碍服务列表里的诱骗文案。

**2. 真正的引导流程（弹窗、跳转或遮罩叠层）不在可见的 DEX 中，已加密下沉**
- 包内 `classes.dex`（1.72 MB）是**诱饵层**：反编译后只有 Braze/Appboy、Glide、Intercom、Unity 和 Discord 日志等三方 SDK 字符串，`travelabout8` 类名出现次数为 **0**。因此，Manifest 里声明的全部 `com.travelabout8.*` Activity/Service/Receiver 实现体都不在这个 DEX 内。
- 真实业务代码由 native 库 [libgiyW.so](<resource-unit:#1.so1>) 在运行期解密后加载：该库导出 `Java_com_travelabout8_ULKkhHuxzPtRfGp_pRGFNbuT`，其字符串池含 `openRawResource`、`getResources`、`loaaugs:raw/sloa`、`dalvik/system/DexClassLoader`，说明它读取 raw 资源后通过 `DexClassLoader` 加载。
- 该 raw 资源是 [resources.arsc/raw/sloaaugs](<resource-unit:#1 file:resources.arsc/raw/sloaaugs>)（459,352 B），头部字节 `99 3f 25 be f7 f5 f1 2d…`、前 2 KB 出现 256 个不同字节值，属于全熵密文，静态不可读。

**3. 叠层/诱导 UI 的载体特征已可静态确认（实现体未见）**
- 应用主题是自定义的 `Theme.AppCompat.Transparent.NoActionBar`：`windowIsFloating=true`、`windowIsTranslucent=true`、`windowBackground=transparent`、`backgroundDimEnabled=false`，具备“透明悬浮、无遮罩变暗”的叠层能力；`p097k`、`p036k`、`p078n` 三个 Activity 与 `p021c`（`excludeFromRecents=true` 全屏）均沿用该主题，`p095o` 使用 `Theme.Dialog`。这些声明共同表明：应用倾向以透明或对话框形态在用户面前弹出内容，而不切换到常规页面。
- 配套权限包含 `WRITE_SETTINGS`、`REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`、`SMS_RECEIVED`（priority 999）、`BIND_DEVICE_ADMIN`、`BIND_NOTIFICATION_LISTENER_SERVICE`，与已知家族（Octo/UTG 类）行为画像一致，但具体拒权循环、获权后动作需要动态复现。

**4. 静态可见性边界**
跳转 `ACTION_ACCESSIBILITY_SETTINGS` / `ACTION_APPLICATION_DETAILS_SETTINGS` 的代码、拒权后的重跳逻辑、获权后动作均位于 `sloaaugs` 密文载荷中，静态不可还原；本次只确认了 Manifest、资源字符串与 native 解密加载链。项目已登记风险 [R-001](<resource-unit:#1 manifest:components>) 覆盖同一命题（冒充 Google Chrome + 西语诱导的无障碍授权骗取），本轮结论与之相互印证，不重复登记。
