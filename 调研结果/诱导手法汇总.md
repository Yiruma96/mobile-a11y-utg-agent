## 一、为什么不能只看单次动态跑测？（三源互补分工）

在 348 款恶意应用中，离线单次动态运行实际分为三类：`131` 款直接复现无障碍诱导页、`147` 款跑出了界面 UTG 但未触达无障碍（登录墙、需先点子功能、离线断网或加壳白屏）、`70` 款因老旧 SDK 安装失败或超时。单看动态会有明显漏检，因此按三源互补整合：

| 证据来源 | 补齐什么盲区 | 在本目录中的位置 |
|---|---|---|
| **动态 UTG 实测** | 打穿强加密壳（`TeaBot`/`Alien`/`FluBot`）；捕获纯静态看不到的**系统页顶部通知横幅压栈**（实测 `74/131` 恶意伴随通知）、桌面 Toast 与 70/70 良性零误报对照 | `01_实测应用分析/*/01_复现无障碍页面/` |
| **静态代码审计** | 补齐「首次启动不暴露」的登录墙、老旧 SDK、后台定时/广播重拉、受限设置分支与 681 条隐藏诱导原文 | 每个应用目录内的 `静态审计报告.md` |
| **网络公开情报** | 补齐海外样本池缺失的**国内电话带外诱骗（银联会议/中银会议/抖音会议）**、**合法远控滥用防误杀红线**及 2024–2026 绕受限/虚拟化/NFC 中继新手法 | `02_网络公开攻击手法/`（18 篇附原文链接） |

## 二、无障碍诱导手法五级隐蔽度分类（L0 → L4）

实测核心定量对比：**良性应用（38 款）跳转无障碍前的应用内说明文本中位数高达 `797 字符`，且 `0/38` 冷启动第一步裸跳**；而恶意应用（131 款）跳转前文本中位数仅 **`79 字符`**，其中 **`43/131`（32.8%）冷启动第一步直接裸跳**。按隐蔽度与对抗深度将全部诱导手法分为 **5 级**：

| 分级 | 形态与核心机制 | 代表样本 / 实战案例 | 端侧识别要点 |
|---|---|---|---|
| **L0 · 裸跳零话术直拉型** | 应用内几乎无任何说明（0 字符），冷启动直接拉起系统无障碍设置页，全靠系统列表里的伪装服务名诱点 | `Anubis`、`BlackRock`、`AbereBot`、`Oscorp`、`Hqwar` | 冷启动 0 步直跳（良性 0%）+ 服务名品牌仿冒 + 空/极短服务描述 |
| **L1 · 单步显性借口弹窗型** | 原生弹窗或极简单页，直白谎称「系统兼容/更新/看视频必需」，通常没有取消键或点取消无效 | `Cerberus`、`Lucy`、`TOASTAMIGO`、`Exobot`、`StealJob`、`BrasDex` | 紧迫/虚假借口文案 + 缺失取消键 + 拒权后重弹 |
| **L2 · 高仿系统/品牌分步引导型** | 用 WebView/截图/GIF 高仿银行安全更新、Play Protect、系统无障碍开关页，或手把手教解锁 Android 13+/鸿蒙「受限设置」 | `Hydra`、`Coper`、`TeaBot`、`Ermac`、`BingoMod`、`BRATA`、[Brokewell](./02_网络公开攻击手法/全球_04_Brokewell假Chrome更新.md)、[SecuriDropper](./02_网络公开攻击手法/全球_01_SecuriDropper与BugDrop绕受限设置.md) | 假系统菜单路径词（`已下载/已安装服务`、`受限设置`）+ 非官方包仿冒品牌 + `应用信息→受限设置→无障碍`跨页链 |
| **L3 · 跨页隐蔽协同与感知劫持型** | 表面几乎无长篇诱导话术，暗中结合**系统页顶部通知横幅**、**桌面持续 Toast**、**零宽字符/30换行空白屏**、**潜伏退桌面浮层**、**黑屏遮罩**或**防卸载秒退** | `FluBot`、`Hook`、`RuMMS`、`GodFather`、`EventBot`、[Crocodilus](./02_网络公开攻击手法/全球_05_Crocodilus黑屏静音窃取助记词.md)、[GodFather 虚拟化](./02_网络公开攻击手法/全球_08_GodFather端侧虚拟化容器劫持.md)、[Snowblind](./02_网络公开攻击手法/全球_09_Snowblind内核seccomp反检测.md) | **不能只看单页 Layout！** 必须结合通知横幅、服务名隐藏字符、拒权自动重拉与黑屏遮罩 |
| **L4 · 带外通话社工 + 伪会议/远控协同型** | **恐吓话术完全在电话/语音中完成（「百万保障扣费/征信受损」），App 界面干净极简**；或直接滥用正规远控，叠加屏幕共享 + 语音教解受限设置 + 无障碍黑屏转账 / NFC 贴卡 | [银联会议](./02_网络公开攻击手法/国内_01_银联会议远程控屏诈骗.md)、[中银/抖音会议](./02_网络公开攻击手法/国内_02_中银抖音等仿冒会议木马.md)、[RustDesk/向日葵滥用](./02_网络公开攻击手法/国内_03_合法远控软件滥用_RustDesk向日葵.md)、[Vultur](./02_网络公开攻击手法/全球_03_Vultur短信回拨与伪装McAfee.md)、[FakeCall](./02_网络公开攻击手法/全球_10_FakeCall拨号劫持语音钓鱼.md)、[NFC中继](./02_网络公开攻击手法/全球_11_RatOn与NGate与SuperCardX_NFC中继.md) | **通话/VoIP 并发态 + 侧载权威品牌会议名 + 录屏/无障碍/悬浮窗三联权限**（对合法远控采场景强警示，严禁误杀应用本身） |

## 四、70 款开源良性对照得出的「防误报红线」

基于 `01_实测应用分析/良性对照/`（70/70 全量，38 款实测走通无障碍）与 `国内_03_合法远控软件滥用` 总结 4 条关键避坑约束：
1. **受限设置教学 ≠ 恶意**：开源侧载良性工具（如 `Tapbar`）也会图文教用户解锁 Android 13+ 受限设置（良性占比 24.3%），不可单靠此特征判黑；
2. **跳后普通底部 `Toast` ≠ 恶意遮罩**：良性应用（如 `Screenshot Tile`）跳转设置后也会弹系统底部 Toast 提示，高危信号应聚焦「顶部通知横幅持续发指令 / 半透明覆盖窗 / 黑屏遮罩」；
3. **按返回退回向导页 ≠ 拒权死循环**：人工核查 70 款良性全集确认，真正的「拒权后自动强拉设置页/诱导弹窗循环」在良性中为 **0/70**；正常向导退回页面或顺延询问下一权限（如 `Buddy Assistant`、`droidVNC-NG`）必须豁免；
4. **正规远控软件本身 ≠ 木马**：对 `RustDesk`/`向日葵`/`ToDesk` 等官方商店合法远控工具，端侧应按「通话并发 + 首次远控无障碍激活 + 切入金融 App」做场景强警示，而非把软件判为恶意。
