# 「银联会议」仿冒官方会议远程控屏与黑屏转账诈骗

- **案例编号**：`INTEL_CN_01` ｜ **地区与活跃期**：中国大陆（2024–2025）
- **诱导隐蔽度分级**：`L4 · 带外通话社工 + 伪会议/远控协同型`
- **为何首次动态运行容易遗漏**：带外通话驱动（App 内无恐吓话术，靠语音指挥）

## 一、伪装形式与接触通道
- **伪装外衣**：银联会议（仿冒中国银联，非官方应用市场侧载 APK，基于开源远控/WebRTC 魔改）
- **带外接触通道**：冒充抖音/电商/保险客服来电 → 转接「银联官方解约专员」实时语音指挥
- **应用内界面特征**：界面极简类似常规视频会议（输入会议号、加入会议、屏幕共享开关），应用内几乎无传统银行木马式恐吓文案；APK 声明 `BIND_ACCESSIBILITY_SERVICE` + `SYSTEM_ALERT_WINDOW` + `MediaProjection` + `READ_SMS`

## 二、典型诱骗话术
- 「您误点了「直播会员 / 百万保障」每月将自动扣费 800–9600 元，不及时关闭将影响个人征信」
- 「应用商店系统升级搜不到，请点击专属链接下载「银联会议」App，输入会议号连线专员协助取消」
- 「请开启「屏幕共享」和「无障碍辅助功能」，手机黑屏/卡顿是系统正在后台安全校验注销，千万不要触碰或挂断」

## 三、攻击步骤与技术链路
- 1. 电话制造扣费/征信恐慌，引导通过微信/短信链接侧载安装「银联会议」APK
- 2. 语音指导输入会议号并调用 `MediaProjectionManager.createScreenCaptureIntent()` 开启实时录屏窥视密码与验证码
- 3. 语音手把手诱导在系统设置中解除「受限设置」并开启无障碍权限与悬浮窗
- 4. 后台结合远控指令与 `AccessibilityService` 模拟点击操作手机银行，同时用全屏黑屏悬浮窗或降低背光制造“黑屏/处理中”遮罩（2025 年北京常女士案被隔空转走 30 余万元）

## 四、端侧可观测信号与鸿蒙防御映射
- 通话中 / VoIP 语音并发期间触发无障碍设置跳转（跨信道上下文）
- 侧载非商店来源 + 应用名/服务名含金融权威机构关键词（「银联」+「会议」）
- 短时间窗口内连续索要「屏幕共享/录屏 + 悬浮窗 + 无障碍」高危权限三联组合
- 跨系统页轨迹出现「应用信息 → 允许受限设置 → 无障碍设置」解锁链
- **鸿蒙端侧防御要点**：侧载安装受限管控 + 通话态高危授权拦截 + `AccessibilityExtensionAbility` 与录屏/悬浮窗/黑屏遮罩组合风控
