## 二、逐案例实战话术、攻击链与 UTG/系统特征拆解

### INTEL_CN_01 · 「银联会议」仿冒官方会议远程控屏与黑屏转账诈骗

- **时间与地区**：中国大陆（2024–2025）｜**分级**：`Level 4 · 带外通话社工 + 伪会议/远控协同型`
- **伪装形式**：银联会议（仿冒中国银联，非官方应用市场侧载 APK，基于开源远控/WebRTC 魔改）
- **带外接触通道**：冒充抖音/电商/保险客服来电 → 转接「银联官方解约专员」实时语音指挥
- **应用内界面特征**：界面极简类似常规视频会议（输入会议号、加入会议、屏幕共享开关），应用内几乎无传统银行木马式恐吓文案；APK 声明 `BIND_ACCESSIBILITY_SERVICE` + `SYSTEM_ALERT_WINDOW` + `MediaProjection` + `READ_SMS`
- **典型诱骗话术（原话/核心剧本）**：
  - 「您误点了「直播会员 / 百万保障」每月将自动扣费 800–9600 元，不及时关闭将影响个人征信」
  - 「应用商店系统升级搜不到，请点击专属链接下载「银联会议」App，输入会议号连线专员协助取消」
  - 「请开启「屏幕共享」和「无障碍辅助功能」，手机黑屏/卡顿是系统正在后台安全校验注销，千万不要触碰或挂断」
- **完整技术杀伤链**：
  - 1. 电话制造扣费/征信恐慌，引导通过微信/短信链接侧载安装「银联会议」APK
  - 2. 语音指导输入会议号并调用 `MediaProjectionManager.createScreenCaptureIntent()` 开启实时录屏窥视密码与验证码
  - 3. 语音手把手诱导在系统设置中解除「受限设置」并开启无障碍权限与悬浮窗
  - 4. 后台结合远控指令与 `AccessibilityService` 模拟点击操作手机银行，同时用全屏黑屏悬浮窗或降低背光制造“黑屏/处理中”遮罩（2025 年北京常女士案被隔空转走 30 余万元）
- **端侧 UTG 与系统上下文可观测特征**：
  - 通话中 / VoIP 语音并发期间触发无障碍设置跳转（跨信道上下文）
  - 侧载非商店来源 + 应用名/服务名含金融权威机构关键词（「银联」+「会议」）
  - 短时间窗口内连续索要「屏幕共享/录屏 + 悬浮窗 + 无障碍」高危权限三联组合
  - 跨系统页轨迹出现「应用信息 → 允许受限设置 → 无障碍设置」解锁链
- **鸿蒙端侧防御映射**：侧载安装受限管控 + 通话态高危授权拦截 + `AccessibilityExtensionAbility` 与录屏/悬浮窗/黑屏遮罩组合风控
- **权威公开参考来源**：中国银联官方严正声明（unionpay.com）；国家金融监督管理总局风险提示（nfra.gov.cn）；上海市人民政府 / 公安反诈预警通报（sh.gov.cn）；新京报 / 人民网 2025 年「银联会议」案件报道（bjnews.com.cn / people.com.cn）

### INTEL_CN_02 · 「中银会议 / 抖音会议 / N+会议 / 国密会议 / 云会议」同源灰产换壳远控族

- **时间与地区**：中国大陆（2024–2025）｜**分级**：`Level 4 · 带外通话社工 + 伪会议/远控协同型`
- **伪装形式**：中银会议、抖音会议、N+会议、国密会议、云视听/云端会议（同套灰产远控源码批量换名换标，常见梆梆/爱加密/自定义壳 + `DexClassLoader` 动态加载）
- **带外接触通道**：冒充短视频平台、微信/支付宝「百万保障」或银行客服电话
- **应用内界面特征**：表面为会议号输入与一键入会界面；核心无障碍控屏载荷常经商业加壳或加密资产动态加载；取得无障碍后将自身图标变透明/隐藏，并在受害人进入应用管理尝试卸载时用 `GLOBAL_ACTION_HOME` / `GLOBAL_ACTION_BACK` 秒退设置页
- **典型诱骗话术（原话/核心剧本）**：
  - 「您开通了每月扣费 800 元的「百万保障 / 直播保险」，不立即取消将连续扣款并上报征信」
  - 「您手机操作太慢看不清，请按我说的在设置里打开「无障碍/辅助功能」方便专员远程代为关闭扣费通道」
  - 「为了保护您的资金安全，需要通过官方指定「中银会议/抖音会议」进行屏幕共享与人脸核验」
- **完整技术杀伤链**：
  - 1. 电话制造「自动扣费 / 影响征信」紧迫感并发送非商店下载链
  - 2. 侧载安装仿冒银行/平台名称的会议木马，需输入骗子口述的会议号才建立 C2/WebSocket 连接
  - 3. 诱导开启屏幕共享与无障碍权限，远程点击填表、读取验证码并在设置页实施防卸载回弹
  - 4. 关键转账阶段制造黑屏/假死并诱导配合人脸识别完成盗刷（2025 年 3 月 65 岁徐女士「中银会议」案）
- **端侧 UTG 与系统上下文可观测特征**：
  - 非官方来源 + 金融/政务/主流平台名称拼接「会议/客服/专员」
  - 首启需输入会议号/连线 C2 才下发远控指令（解释单机离线首启不暴露原因）
  - 无障碍授权后对「应用信息/无障碍设置」页面执行高频强行返回（防卸载秒退特征）
- **鸿蒙端侧防御映射**：结合应用市场签名校验、通话期屏幕共享+无障碍联动阻断、设置页防劫持保护
- **权威公开参考来源**：北京市人民政府 / 央视新闻反诈通报（beijing.gov.cn / cctv.com）；福建省人民政府 / 中国银行官方提醒（fujian.gov.cn / bankofchina.com）；人民网 2025 年 3 月「中银会议」诈骗报道（people.com.cn）
