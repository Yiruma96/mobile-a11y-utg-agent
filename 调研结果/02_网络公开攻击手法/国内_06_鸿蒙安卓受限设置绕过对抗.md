# 鸿蒙 / 安卓「受限设置」与「纯净模式」语音+伪弹窗手把手解锁对抗

- **案例编号**：`INTEL_CN_06` ｜ **地区与活跃期**：中国大陆及全球（2024–2025）
- **诱导隐蔽度分级**：`L2 · 高仿系统/品牌分步引导型`
- **为何首次动态运行容易遗漏**：跨系统多页引导链（先跳应用信息页解锁受限，再二次跳无障碍）

## 一、伪装形式与接触通道
- **伪装外衣**：各类侧载涉诈/木马 APK 针对 Android 13–15 与 HarmonyOS「受限设置 / 纯净模式」的对抗引导
- **带外接触通道**：应用内分步截图、悬浮窗箭头指引，或视频/语音通话实时手把手教学
- **应用内界面特征**：在 UTG 轨迹上呈现典型的「三段跨系统页跳转」：`恶意 App 图文教学页 → 系统应用信息页（App Info / InstalledAppDetails）→ 右上角菜单“允许受限设置” → 系统无障碍列表页`

## 二、典型诱骗话术
- 「出于安全考虑此设置当前不可用？请先点确定，再进入「应用信息」点右上角三个点，选择「允许受限设置」即可恢复正常」
- 「请按照图示先关闭纯净模式/解除受限保护，这是官方业务办理必需步骤」

## 三、攻击步骤与技术链路
- 1. 侧载安装触发 OS 受限设置（无障碍开关灰显锁定）
- 2. 应用内展示分步截图或由电诈人员通话指导用户进入应用信息页手动点击「允许受限设置」
- 3. 解锁后再次拉起无障碍设置页完成授权

## 四、端侧可观测信号与鸿蒙防御映射
- 应用内文本出现「受限设置 / Restricted Settings / 右上角三点 / 允许受限设置 / 纯净模式」等系统防护绕过教学词
- UTG 出现 `App → AppInfoActivity → AccessibilitySettingsActivity` 的短时顺序跳转特征
- 需与良性开源侧载工具（如本数据集良性样本 `Tapbar`）区分：结合应用身份是否仿冒、是否存在取消/跳过键、是否伴随通话或拒权循环
- **鸿蒙端侧防御要点**：监测 `应用信息页 → 解除受限设置 → 无障碍页` 的连续 UTG 转移链，对侧载应用触发二次冷静期与反诈核验
