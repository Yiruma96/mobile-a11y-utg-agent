## 分析结论（静态定向核验）

**核心发现：该样本的“引导”完全没有任何说明文案，属于纯跳转加定时重跳型强制引导，并配合无障碍服务自身的自动点击来完成授权。**

- **冷启动入口**：[MainActivity.onCreate](<resource-unit:#1.dex1 code:com.cosmos.starwarz.MainActivity#onCreate>) 使用 `Theme.Transparent`（透明、无界面），清空 `uplink` 偏好并生成 `botid`，启动 `Geny2` 服务后立刻调用 `disable()` 把**自己（LAUNCHER 组件）设为 DISABLED**，导致桌面图标在首次启动后消失。
- **定时跳转核心**：[Geny2.onStartCommand](<resource-unit:#1.dex1 code:com.cosmos.services.Geny2#onStartCommand>) 用 `Timer.scheduleAtFixedRate(..., 0L, 8000L)` 每 8 秒执行一次 [b.b.c.c.run](<resource-unit:#1.dex1 code:b.b.c.c#run>)。该方法先用 [Geny2.e](<resource-unit:#1.dex1 code:com.cosmos.services.Geny2#e>) 读 `Settings$Secure.enabled_accessibility_services` 判断无障碍是否已开启；未开启则 `startActivity(new Intent("android.settings.ACCESSIBILITY_SETTINGS").setFlags(268435456))` 直接跳到系统无障碍设置页，没有任何前置说明、弹窗或教学页；返回后 8 秒再跳，形成无退出路径的拒权循环。
- **文案载体为零**：[res/values/strings.xml](<resource-unit:#1 file:res/values/strings.xml#L44>) 中 `accessibility_service_description` 为**空字符串**，[res/xml/config.xml](<resource-unit:#1 file:res/xml/config.xml#L2-L3>) 未声明 `android:description`，全包无 layout 目录，也无本地 HTML 或 assets 引导页。无障碍列表项只显示应用名 **Protezione Cliente**（意大利语“客户保护”），无任何用途解释，属于空白描述伪装。
- **获权后的连锁动作**（同一 run 方法内）：无障碍已开启 → 检测 `android:get_usage_stats`，未授权则跳 `USAGE_ACCESS_SETTINGS`；已授权则跳 `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`，`sleep(3000)` 后拉起透明 Activity [React](<resource-unit:#1.dex1 code:com.cosmos.starwarz.React#onCreate>)，把清单中**全部危险权限**一次性 `requestPermissions(...,124)`；被拒则再次 `startActivity(React)` 自跳循环，全部允许后启动 `PJService`/`MyService` 并自我禁用。
