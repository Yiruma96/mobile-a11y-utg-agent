## 二、逐案例实战话术、攻击链与 UTG/系统特征拆解

### INTEL_CN_01 · 「银联会议」仿冒官方会议远程控屏诈骗

- **时间与地区**：中国大陆（2024–2025）｜**分级**：`Level 4 · 带外通话社工 + 伪会议/远控协同型`
- **伪装形式**：银联会议（仿冒中国银联，非官方应用商店侧载 APK）
- **带外接触通道**：冒充抖音/电商/保险客服来电 → 转接「银联官方解约专员」
- **应用内界面特征**：界面极简类似常规视频会议（输入会议号、加入会议、屏幕共享开关），**应用内几乎无传统银行木马式恐吓文案**，社工恐吓主要发生在通话带外信道
- **典型诱骗话术（原话/核心剧本）**：
  - 「您误点了「直播会员 / 百万保障」每月将自动扣费 800–9600 元，不及时关闭将影响个人征信」
  - 「应用商店系统升级搜不到，请点击专属链接下载「银联会议」App，输入会议号连线专员协助取消」
  - 「请开启「屏幕共享」和「无障碍辅助功能」，手机黑屏/卡顿是系统正在后台安全校验注销，千万不要触碰或挂断」
- **完整技术杀伤链**：
  - 1. 引导绕过官方应用商店通过链接/二维码侧载安装「银联会议」APK
  - 2. 语音指导输入会议号并开启 MediaProjection 屏幕共享实时窥屏
  - 3. 语音手把手诱导在系统设置中解除「受限设置」并开启无障碍权限（AccessibilityService）与悬浮窗
  - 4. 后台结合远控指令与无障碍模拟点击操作手机银行，同时触发黑屏/「系统处理中」遮罩阻断受害人感知与操作（2025 年北京常女士案被隔空转走 30 余万元）
- **端侧 UTG 与系统上下文可观测特征**：
  - 通话中/VoIP 语音并发期间触发无障碍设置跳转（跨信道上下文）
  - 侧载非商店来源 + 应用名/服务名含金融权威机构关键词（「银联」+「会议」）
  - 短时间窗口内连续索要「屏幕共享/录屏 + 悬浮窗 + 无障碍」高危权限三联组合
  - 跨系统页轨迹出现「应用信息 → 允许受限设置 → 无障碍设置」解锁链
- **鸿蒙端侧防御映射**：侧载安装受限管控 + 通话态高危授权拦截 + `AccessibilityExtensionAbility` 与录屏/悬浮窗组合风控
- **权威公开参考来源**：中国银联官方严正声明（unionpay.com）；国家金融监督管理总局风险提示（nfra.gov.cn）；上海市人民政府 / 公安反诈预警通报（sh.gov.cn）；新京报 / 人民网 2025 年「银联会议」案件报道（bjnews.com.cn / people.com.cn）

### INTEL_CN_02 · 「中银会议 / 抖音会议 / 国密会议 / 云会议」系列仿冒会议木马

- **时间与地区**：中国大陆（2024–2025）｜**分级**：`Level 4 · 带外通话社工 + 伪会议/远控协同型`
- **伪装形式**：中银会议、抖音会议、国密会议、云视听/云端会议等（基于开源远控/WebRTC 框架二次打包换壳）
- **带外接触通道**：冒充短视频平台、微信/支付宝「百万保障」或银行客服电话
- **应用内界面特征**：表面为会议号输入与一键入会界面，申请 `BIND_ACCESSIBILITY_SERVICE` + `SYSTEM_ALERT_WINDOW` + `RECORD_AUDIO` + 投屏权限；部分样本授权后隐藏图标并在用户尝试卸载时用无障碍自动点「返回」防卸载
- **典型诱骗话术（原话/核心剧本）**：
  - 「您开通了每月扣费 800 元的「百万保障 / 直播保险」，不立即取消将连续扣款并上报征信」
  - 「您手机操作太慢看不清，请按我说的在设置里打开「无障碍/辅助功能」方便专员远程代为关闭扣费通道」
  - 「为了保护您的资金安全，需要通过官方指定「中银会议/抖音会议」进行屏幕共享与人脸核验」
- **完整技术杀伤链**：
  - 1. 电话制造「自动扣费 / 影响征信」紧迫感
  - 2. 侧载安装仿冒银行/平台名称的会议木马
  - 3. 诱导开启屏幕共享窥视网银密码与短信验证码，叠加无障碍权限自动点击、填表与防卸载
  - 4. 关键转账阶段制造黑屏/假死并配合人脸识别欺骗完成盗刷（2025 年 3 月 65 岁徐女士「中银会议」案）
- **端侧 UTG 与系统上下文可观测特征**：
  - 非官方来源 + 金融/政务/主流平台名称拼接「会议/客服/专员」
  - 低字数极简入口页 + 语音驱动直跳受限设置/无障碍设置
  - 无障碍授权后拦截设置/应用管理页面（防卸载回弹）
- **鸿蒙端侧防御映射**：结合应用市场签名校验、通话期屏幕共享+无障碍联动阻断、黑屏遮罩窗口监测
- **权威公开参考来源**：北京市人民政府 / 央视新闻反诈通报（beijing.gov.cn / cctv.com）；福建省人民政府 / 中国银行官方提醒（fujian.gov.cn / bankofchina.com）；人民网 2025 年 3 月「中银会议」诈骗报道（people.com.cn）

### INTEL_CN_03 · 合法远控软件滥用（向日葵 / ToDesk / AirDroid / 腾讯会议）带外诱骗开启无障碍

- **时间与地区**：中国大陆（2023–2025）｜**分级**：`Level 4 · 带外通话社工 + 伪会议/远控协同型`
- **伪装形式**：100% 合法上架的远控/会议软件（向日葵、ToDesk、AirDroid、Zoom、腾讯会议等）
- **带外接触通道**：冒充客服理赔、网课退费、机票退改签、虚假投资理财或婚恋交友语音指导
- **应用内界面特征**：**应用本身 100% 合规且来自官方商店，静态与常规动态检测均呈良性特征**；恶意性完全来自「陌生人通话并发 + 远控授权后访问手机银行/支付软件」的运行时场景组合
- **典型诱骗话术（原话/核心剧本）**：
  - 「下载正规应用商店的「向日葵/ToDesk」，发给我识别码和验证码，我远程帮您调试设备/操作退费」
  - 「系统提示需要打开「辅助功能/无障碍」才能远程帮您点，这是正规大厂软件很安全」
- **完整技术杀伤链**：
  - 1. 规避侧载拦截：直接诱导受害人从正规应用市场下载合法远控软件
  - 2. 语音指导开启无障碍权限以启用被控端免 Root 远程操控
  - 3. 受害人提交设备识别码后，攻击者远程接管手机并诱导进入网银/支付应用转账
- **端侧 UTG 与系统上下文可观测特征**：
  - 该类场景是**纯应用级静态/单次 UTG 判黑的天然边界**（绝不能将向日葵/ToDesk 判为恶意木马）
  - 正确防御策略：**场景化高风险强提醒而非封杀应用**——检测到「陌生来电/通话中 + 首次开启远控类应用无障碍 + 随后打开银行/支付应用」时弹出强反诈弹窗与敏感界面防窥保护
- **鸿蒙端侧防御映射**：不误报正规远控工具本身；在端侧通过「通话态 + 远控无障碍激活 + 金融 App 前台切换」触发反诈强警示与金融隐私防录屏/防无障碍读取
- **权威公开参考来源**：新华网 / 国家反诈中心 / 光明网 2024–2025 远程控制防骗预警（xinhuanet.com / gmw.cn）；国家金融监督管理总局风险提示（nfra.gov.cn）

### INTEL_CN_04 · 鸿蒙/安卓「受限设置」语音与伪弹窗手把手解锁对抗

- **时间与地区**：中国大陆及全球（2024–2025）｜**分级**：`Level 2 · 高仿系统/品牌分步图文引导型`
- **伪装形式**：各类侧载涉诈/木马 APK 针对 Android 13–15 与 HarmonyOS「受限设置」的绕过引导
- **带外接触通道**：应用内图文步骤页、悬浮窗指引，或视频/语音通话实时手把手教学
- **应用内界面特征**：在 UTG 轨迹上呈现典型的「三段跨系统页跳转」：`恶意 App 图文教学页 → 系统应用信息页（App Info / InstalledAppDetails）→ 右上角菜单“允许受限设置” → 系统无障碍列表页`
- **典型诱骗话术（原话/核心剧本）**：
  - 「出于安全考虑此设置当前不可用？请先点确定，再进入「应用信息」点右上角三个点，选择「允许受限设置」即可恢复正常」
  - 「请按照图示先关闭纯净模式/解除受限保护，这是官方业务办理必需步骤」
- **完整技术杀伤链**：
  - 1. 侧载安装触发 OS 受限设置（无障碍开关灰显锁定）
  - 2. 应用内展示分步截图或由电诈人员通话指导用户进入应用信息页手动点击「允许受限设置」
  - 3. 解锁后再次拉起无障碍设置页完成授权
- **端侧 UTG 与系统上下文可观测特征**：
  - 应用内文本出现「受限设置 / Restricted Settings / 右上角三点 / 允许受限设置 / 纯净模式」等系统防护绕过教学词
  - UTG 出现 `App → AppInfoActivity → AccessibilitySettingsActivity` 的短时顺序跳转特征
  - 需与良性开源侧载工具（如本数据集良性样本 `Tapbar`）区分：结合应用身份是否仿冒、是否存在取消/跳过键、是否伴随通话或拒权循环
- **鸿蒙端侧防御映射**：监测 `应用信息页 → 解除受限设置 → 无障碍页` 的连续 UTG 转移链，对侧载应用触发二次延迟冷静期与反诈核验

- **伪装形式**：Dropper-as-a-Service（伪装 Google Chrome / 实用工具 / 杀毒应用，投放 SpyNote、Ermac、Anatsa 等）
- **带外接触通道**：钓鱼网站、短信链接或第三方商店侧载
- **应用内界面特征**：阶段一壳程序本身**完全不声明 `BIND_ACCESSIBILITY_SERVICE`**，首次运行看起来只是“下载更新器”；安装二阶段载荷后才出现无障碍诱导页（典型的「首启不暴露」多阶段投放）
- **典型诱骗话术（原话/核心剧本）**：
