## 结论要点（纯静态定向核验）

**能确认的部分（Manifest、资源与配置均未加密）**

- 无障碍服务 [InjAccessibilityService](<resource-unit:#1 manifest:components>) 的权限配置 [res/xml/opdbpdfhlirtlw.xml](<resource-unit:#1 file:res/xml/opdbpdfhlirtlw.xml>) 权限极高：`typeAllMask`、`canRetrieveWindowContent`、`canPerformGestures`、`canRequestFilterKeyEvents`、`flagRequestTouchExplorationMode`，并且 **`settingsActivity=""` 且无 `android:description`** → 系统无障碍列表里该服务没有说明文字，也不会显示配置入口，只有一个裸开关。
- 引导文案全部以明文放在 [res/values/strings.xml](<resource-unit:#1 file:res/values/strings.xml>) 中，呈现的是一套**“分步教学 + 假更新 + 假 Google 品牌”**的引导语料：`instructions_hint`/`instruction_step_1..4`/`instruction_button_activate`（"Go to settings"）、`acc_message`（"Please enable Portal service under Accessibility settings"）、`check_in_services_message`（"Check in 'Downloaded Services' list: %s"），以及小米/三星定制变体（`xiaomi_instruction_step_2` 要求“允许后台弹出窗口”、`samsung_instruction_step_2` 要求“Appear on top”）。
- 另有独立的 **Play Protect 伪造页语料**：`enablePlayProtect_message`（"To install Security update you must disable 'Scan device' option!"）、`services_playProtect`/`services_playScanningDisableBtn`（"turn off"）/`servicesButton_Uninstall`/`servicesButton_ForceStop`，配合“Security update”话术，诱导用户关闭系统防护，并模仿系统应用详情页的“卸载/强行停止”按钮。
- **身份伪装三重叠加**：桌面名 `BAWAG Security`（奥地利银行品牌）；`app_name` 资源为 `GoogleReader`；`activity-alias` 提供 `label="Settings"` + `icon=@drawable/ic_settings_main` + 默认关闭（`enabled="false"`）的伪“设置”图标；`HelperAdmin$MyHomeReceiver` 的描述为 `Google - do not disable this app`（设备管理器列表里冒充 Google）；`LockerActivity` 带 `HOME` category 的伪桌面。

**被加密、静态不可还原的部分**

- DEX 中**不存在** `com.digpbzgcd.pelnoisux.*` 任何类（`search_function_definitions` / `list_codebase` 均为 0 命中），Manifest 声明的 `InjAccessibilityService`、`MainActivity`、`PermissionsActivity`、`NLService` 全部缺失。
- 真实代码藏在 [assets/yi8gGhj/GahijUfed1.88a](<resource-unit:#1 file:assets/yi8gGhj/GahijUfed1.88a>)（2.24 MB）与 [GahijUfed2.88a](<resource-unit:#1 file:assets/yi8gGhj/GahijUfed2.88a>)（420 KB）：zlib 外层可解，内层为非常规加密的 DEX（无 `dex\n` 魔数、非单字节 XOR、非多层 zlib）。
- 装载器 [com.beans.kaspo.g](<resource-unit:#1.dex1 code:com.beans.kaspo.g>) 用字符串 XOR 反射调用 `ActivityThread`（`currentActivityThread`/`getInstrumentation`/`newApplication`/`mAllApplications`/`mInitialApplication`/`mBoundApplication`），把 Manifest 里的 `android:name` 强行改写为 `com.digpbzgcd.pelnoisux.App` 并替换进程 Application——即 **MultidexPacker 式加密分阶段载荷**（APKiD 亦标记 `packer: MultidexPacker`、`anti_vm`、`anti_debug`）。

因此：**无障碍诱导的“文案与配置”完全静态可见，“页面流转控制代码”（何时跳设置、是否 onResume 重跳、是否叠遮罩、是否自点开关）在加密资产内，未能静态还原。**

**建议的 UTG 抓取时机**：`ACTION_ACCESSIBILITY_SETTINGS` 无法从 DEX 静态定位，因此不能靠静态断点，应在**冷启动后 3 秒内对 Activity 栈做轮询截图**，并在 `dumpsys window` 出现 Settings 包名（`com.android.settings/.Settings$AccessibilitySettingsActivity`、`...$HighPowerApplicationsActivity`、`...applications.ManageApplications`）时立即抓帧；同时监测本应用是否在系统设置页之上压入 `Theme.Translucent.NoTitleBar.Fullscreen` 的 Activity（`MainActivity`/`MainActivity2`/`PermissionsActivity`/`core.injects_core.Screen`）形成遮罩。
