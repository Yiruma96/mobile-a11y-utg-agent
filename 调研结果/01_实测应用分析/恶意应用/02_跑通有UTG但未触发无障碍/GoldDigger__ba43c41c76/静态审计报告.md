## 分析结论（静态定向核验，14 次工具内收口）

**1. 加固事实：真实引导逻辑不在可见 DEX 中**
- `apkid` 判定 `classes.dex` 与 `assets/vwwwwwvwww/*/libdpt.so` 均为 **DPT Shell** 加固；可见 DEX 仅含 `ProxyApplication`、`ProxyComponentFactory`、`JniBridge` 等壳引导类（`com.nashsiqiu.shell.*`），**没有任何业务类**。
- `assets/app_name` 明文给出真实 Application 类名 `c6ecd9847aeb94701a6ec65bbdabca377.ca9b7bdb084d94dcda32ec1412eb21fe1.c6a0c221f46f343cb83fa06200f0d6c20.App`；`assets/OoooooOooo`（2.5 MB，高熵）为加密载荷 → 业务代码在运行期解密动态加载。**因此 `ACTION_ACCESSIBILITY_SETTINGS` 跳转点、引导弹窗/Activity 的具体实现无法静态定位**（DEX 中 `ACCESSIBILITY_SETTINGS`、`go_to_accessibility_setting`、`FocusService` 字符串命中数均为 0）。

**2. 无障碍服务声明与配置（可静态确认）**
- [AndroidManifest.xml](<resource-unit:manifest_decoded.xml file:all>) 声明 `...service.FocusService`，`BIND_ACCESSIBILITY_SERVICE` 保护，`android:label` 复用应用名 `@7F100074`（即 `SKY Airline`，系统无障碍列表显示名与桌面名一致，不暴露真实用途）。
- [touch_accessibility_service_config.xml](<resource-unit:touch_accessibility_service_config.xml file:all>)：`accessibilityEventTypes=0xFFFFFFFF`、`feedbackType=0xFFFFFFFF`、`notificationTimeout=10`、`canRetrieveWindowContent=true`、`canPerformGestures=true`、`canRequestEnhancedWebAccessibility=true`，并显式 **`isAccessibilityTool="true"`** —— 一个"航空公司订票"应用自我声明为无障碍工具，用于规避系统在列表项上展示的"可读取屏幕全部内容"隐私警告。

**3. 引导文案确实存在（资源层证据，代码层缺失）**
`resources.arsc` 字符串池中存在**编号分步教学**与跳设置锚点：`1. 给出"ssoconnect 安全系统"辅助功能"辅助功能模式"启用访问`、`请单击以启用辅助功能。`、`go_to_accessibility_setting`、`check_focus_service`、`float_window_permission_tip`、`如果没有开启权限 会影响部分功能的正常使用。`，以及受限设置分步文案 `设置 → 应用程序 → 当前App → 权限`。这些键名/文案对应的承载类（`SplashActivity`/`CheckPermissionActivity`/`ActivationActivity`/`TransplentPermissionActivity`）代码体全部在加密载荷内。

**4. 身份伪装**
显示名/无障碍服务名 `SKY Airline`（真实智利航空品牌）；Manifest 同时存在**两套重复 Activity**（`fdaffmfdaf.dfdafafdf.gfgfgfg.LoginActivity`/`AirLinesRegister*` 与 `c6ecd9…ui.LoginActivity`/`AirLinesRegister*`），并注入非法属性名 `________manifest____android_name="false"` 干扰第三方解析器。

**5. 获权后的行为线索**
资源中 `onServiceConnected:服务启动了`、`客户端收到27指令开始获取黑屏助手数据,检测到无障碍状态为：%s`、`发送黑屏助手数据时检测到无障碍状态为false`，表明无障碍状态作为指令执行前置条件被上报/校验；配合 `READ_SMS`/`SEND_SMS`/`READ_CONTACTS`/`RECORD_AUDIO`/`SYSTEM_ALERT_WINDOW`/`QUERY_ALL_PACKAGES` 与自定义权限 `*.manual.dump`、`*.backtrace.warmed_up`、`*.matrix.permission.PROCESS_SUPERVISOR`，与 GoldDigger 家族"无障碍 + 短信 + 屏幕录制/悬浮窗覆盖"组合一致。

**6. 覆盖边界**
引导页 UI 载体（原生 Dialog / WebView / 悬浮遮罩）、是否存在取消按钮、拒权后是否 `onResume` 死循环重跳、是否教用户开启"受限设置"，均需运行期 UTG 观测；静态侧仅能确认"存在编号式分步引导文案 + 跳系统无障碍设置锚点 + 悬浮窗提示资源"。
