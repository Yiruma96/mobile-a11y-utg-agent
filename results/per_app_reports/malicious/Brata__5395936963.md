## 分析结论（定向核验：无障碍授权 UTG 页面流转）

**静态可见性：完全可见**（无加壳、无远端 HTML、无加密载荷；引导文案全部为 Java 硬编码字符串或 `strings.xml` 资源）

**核心链路（纯运行期页面流转）**

1. **冷启动入口**：`MainActivity` 为唯一 LAUNCHER Activity（`excludeFromRecents=true`），`onCreate` 只调用 `setContentView` 加载 `activity_main`，随后起线程执行 `MainActivity#c()`。布局中仅有仿冒 logo、应用名 TextView（`@string/app_name`）与一个 `visibility="invisible"` 的 `Ativar` 按钮——首屏几乎无可用功能。
2. **分支判定**：`c()` 用 `g.b(ctx)`（远端配置 `https://ps.jclapp.net/android` 解析出的目标包名列表）与 `f.e(ctx)`（读 `Settings.Secure.accessibility_enabled`）分流：无障碍未开启 → 走引导链；已开启 → 走“更新成功 + 隐藏图标”链。
3. **引导说明页（原生不可取消 AlertDialog）**：`MainActivity$a#b` 构造 `AlertDialog.Builder`，`setCancelable(false)`，标题 `Atenção`，正文为 `Html.fromHtml("Para atualizar você precisa ativar o serviço de acessiblidade em <b>Serviços > " + getString(app_name) + "</b> na proxima tela.")`，唯一中性按钮 `Continuar`。无“取消/跳过/以后再说”。
4. **跳受限设置**：`MainActivity$a$1#onClick` 直接 `startActivity(new Intent("android.settings.ACCESSIBILITY_SETTINGS"))`，并加 `FLAG_ACTIVITY_NEW_TASK|NEW_TASK…`（268435456/32768/8388608）。无 `ACTION_APPLICATION_DETAILS_SETTINGS`、无 Android 13+“允许受限设置”教学（`targetSdk=28`，依赖旧策略）。
5. **拒权反馈循环**：未开启分支同时启动 `Timer` 每秒执行 `MainActivity$c#run`；用户从系统设置返回后，`MainActivity$5$1#onClick` 再次弹出同一对话框；45 秒仍未开启 → `MainActivity.a()` 置 `b=true` 并 `finish()` → `onDestroy` 检测到 `b` 后 100ms 重投 `MainActivity$2`，`startActivity(getIntent())` 自我重启，形成“重弹—重启—再弹”闭环。
6. **获权后动作**：`Timer` 检测到 `accessibility_enabled==1` 即跳 `ACTION_MAIN`+`CATEGORY_HOME` 回桌面；`AccService#onServiceConnected` 立刻注册 `i.a()` 与 `RegisterReceiverService`；`MainActivity$3` 弹 `Atualização aplicada com sucesso.`；15 秒后 `MainActivity$4` 用 `setComponentEnabledSetting(MainActivity, 2, 1)` **禁用启动图标**（防止用户找到并卸载）。

**文案呈现位置**：系统无障碍列表描述（`accessibility_service_config.xml` → `@string/accessibility_description`）、不可取消 AlertDialog 标题/正文/按钮、`activity_main.xml` 的 TextView 与 `Ativar` 按钮、获权后的“更新成功”弹窗。全部本地资源，无 WebView/悬浮窗引导。

**UTG 检测建议**：在 `ACCESSIBILITY_SETTINGS` 跳转瞬间与冷启动首帧即抓取；关键判据为“不可取消 + 单按钮 + 文案把授权包装成更新步骤”。
