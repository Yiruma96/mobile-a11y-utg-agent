# 合法远控软件带外滥用（RustDesk / 向日葵 / ToDesk / AirDroid / 腾讯会议）

- **案例编号**：`INTEL_CN_03` ｜ **地区与活跃期**：中国大陆及全球（2023–2025）
- **诱导隐蔽度分级**：`L4 · 带外通话社工 + 伪会议/远控协同型`
- **为何首次动态运行容易遗漏**：应用 100% 合法（零恶意代码），仅在特定通话+金融场景被社工滥用

## 一、伪装形式与接触通道
- **伪装外衣**：100% 正规上架的开源/商业远程控制与会议软件（RustDesk、向日葵、ToDesk、AirDroid、AnyDesk、Zoom、腾讯会议）
- **带外接触通道**：冒充电商理赔、网课退费、机票退改签、虚假投资理财或婚恋交友语音指导
- **应用内界面特征**：应用本身完全合规且来自官方应用商店，静态代码与常规动态 UTG 均呈良性特征（RustDesk 等已在受控端内置反诈倒计时警示，但面对被洗脑主动配合的受害人仍会被手动点过）

## 二、典型诱骗话术
- 「直接去官方应用商店下载「RustDesk / 向日葵 / ToDesk」，把识别码和临时密码发给我，我远程帮您操作退费」
- 「弹窗倒计时警示不用管，那是正常软件提示，点同意并开启「无障碍/辅助功能」就能免 Root 远程协助」

## 三、攻击步骤与技术链路
- 1. 规避侧载与受限设置拦截：直接引导受害人从官方商店安装正规远控软件
- 2. 语音指挥受害人跳过软件内反诈警示并授予无障碍权限（实现远端免 Root 模拟点击）
- 3. 提交设备 ID/验证码建立受控会话，攻击者远程接管手机并打开网银/支付软件转走资金

## 四、端侧可观测信号与鸿蒙防御映射
- 这是**纯应用级静态/单次 UTG 判黑的天然红线**：绝不能将向日葵/ToDesk/RustDesk 误判为恶意木马
- 正确端侧防御范式：**场景化风控警示**——监测到「陌生来电/通话中 + 首次激活远控类无障碍 + 切入银行/支付应用」时弹出强反诈阻断页并自动开启敏感窗口防录屏/防无障碍读取
- **鸿蒙端侧防御要点**：不误报正规远控应用本身；端侧以「通话态 + 远控无障碍激活 + 金融 App 前台切换」触发反诈冷静期与金融隐私防窥
