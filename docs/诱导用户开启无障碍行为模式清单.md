# 移动端诱导用户开启无障碍行为模式清单与低功耗事中 UTG 捕获指南（终校统一版）

> **实证与清洗口径（全口径校核）**：基于 **1,769 个三源去噪核验无障碍 APK**（MalRadar 2014–2021 `1,227` + MalwareBazaar 2022–2026 `472` + 开源良性 `70`）及 **418 份「一应用一文件」代码级逆向报告**（[per_app_reports/INDEX.md](per_app_reports/INDEX.md)）。本版严格修正了初版存在的**加壳样本推测标签污染、非无障碍误入噪声、LLM 真值提示泄露、良恶口径不对称及首次窗口与拒权二轮时序混算**问题，将 348 份恶意逆向样本划分为四个互斥队列：
> - **主动可观测诱骗池（`n = 224`）**：MalRadar `134` + MalwareBazaar `90`，覆盖 `63` 个独立命名恶意家族——**本清单所有诱导模式占比与良恶对照的唯一合法恶意分母**；
> - **零应用内引导潜伏 / Xposed / Root 提权池（`n = 17`）**：无应用内引导页与设置跳转，仅靠服务名伪装静待误点或 Xposed/Root 自授权（单独归类，不混入主动诱导）；
> - **强加壳 / VMP / AES 密文遮蔽池（`n = 96`）**：静态不可还原引导链路（初版误将其中 `66` 例冷启动、`45` 例遮罩、`17` 例教唆忽视警告推测标签混入统计，本版**全部剥离**，交由离线动态 GUI-Owl 采集验证）；
> - **静态初筛误入非无障碍样本（`n = 11`）**：经代码逆向证伪不含无障碍引导的样本（4 例 `HiddenAd`、3 例 `Etinu`、2 例 `Unattributed` 调试面板、1 例 `GhostClicker` 快捷方式、1 例 `meftadon` 空壳），**已剔除出有效分母**（剔除后 2022–2026 近期有效池 `n = 167` 的真实静态不透明占比为 **`122/167 = 73.1%`**，其中强加密 `74` 例 + 远端/部分动态 `48` 例）。

## 一、破局端侧功耗与事中化难题：免除「每页切换全量抓 Layout」

### 1.1 与 ClickFix 的本质差异：时序不对称困境（Temporal Asymmetry Dilemma）

| 维度 | ClickFix（剪贴板/终端诱骗） | 移动端无障碍权限诱导（Accessibility Inducement） |
| --- | --- | --- |
| **诱导与触发的相对时序** | 触发事件（写入剪贴板）发生时，恶意网页**仍在屏幕前台** | 诱导界面（Dialog / WebView / 假设置）出现在**进入系统设置之前**；跳进系统设置后原诱导页已被切走甚至 `finish()` |
| **纯事后捕获的缺陷** | 单次触发即可抓到当前完整网页 | 等用户**事后**打开无障碍开关或已切入系统设置再抓，前置诱导画面已消失（且 DVa USENIX Sec'24 证实 92% 获权木马会阻止撤权） |
| **朴素全时捕获的代价** | 无需全时监控 | 若对侧载应用**每次页面切换都做全量 Layout 树遍历**，CPU、IPC、内存与功耗开销均不可接受，且存在隐私合规负担 |
| **可利用的 OS 黄金窗口** | 复制到粘贴存在人类操作间隔 | 无障碍与高危管控属 **`manual_settings` 多步人工开关**：跳进设置页到用户点进「已下载的应用 → 目标服务 → 打开开关 → 点系统二次确认允许」天然存在 **3–10 秒人工导航窗口** |

### 1.2 单一核心思想：**以系统设置跳转为单点触发锚、以手工授权导航窗为事中核验期，将全时 UI 监控坍缩为跳前单帧取证**

严格遵循 **零 EDR、零全时 Layout 轮询、授权生效前事中拦截** 约束，拆解为四步低功耗状态机：

1. **安装态三元限域（99.9% 日常应用零开销）**：仅对同时满足「① 非应用市场侧载/企业分发；② 声明无障碍或高危 `manual_settings` 能力；③ 当前处于**未授予**状态」的目标激活轻量监听；一旦授权完成即自动卸载。
2. **常态零 Layout 骨架环缓（AMS/WMS 元数据，功耗 ≈ 0）**：日常运行期**绝对不做任何 `dumpLayout` / 控件树序列化**；仅旁路复用 AMS/WMS 原本维护的极轻量元数据环缓（最近 K = 8 帧，`< 2 KB` 内存）：`(timestamp, bundleName, abilityName, windowType, flags, lastUserTouchTime)`，零开销获取导航深度 d、是否用户触摸驱动、跳后 0–2 s 异源浮窗压栈及拒权 30 s 自动重跳。
3. **跳前单次同步快照（`t0 - ε`，覆盖 `218/224 = 97.3%` 显式跳设置样本）**：拦截受限目标调用 `startAbility` / `startActivity` 指向系统无障碍设置页（或受限预热应用详情页）的**毫秒瞬间**（新页切入覆盖前），同步抓取 **1 帧**当前前台诱导窗口控件树 + 最后点击控件文本（专抓 `BrasDex` 假取消键）。
   - **反 `finish()` 擦除兜底（精确工程澄清）**：针对 `Escobar` 等先调 `finishAndRemoveTask()` 销毁前页再跳设置的对抗，优先读取受限应用 Dialog/WebView 销毁回调的 1 槽纯文本摘要；若退回到 WMS/RenderService 离场窗口快照（`TaskSnapshot`），须明确其底层为**像素位图（Bitmap）而非结构化控件树**，需走单帧端侧轻量 OCR 恢复文本。
   - **反「纯口头图文、不调用 `startAbility`」手动导航绕过**：若恶意应用仅展示静态教程、诱导用户自行按 Home 键进入设置，则在用户手动点开系统无障碍列表目标服务详情页时触发兜底核验（读取服务名/描述 + 包名品牌元数据 + 最近 1 个前台应用包名关联）。
4. **双阶段事中处置（严守首次窗口与拒权二轮的时序边界）**：
   - **阶段 A · 首次 3–10 s 人工设置导航窗（真正事中，不含拒权死循环！）**：在用户点开开关与最终系统二次确认「允许」弹窗前的 3–10 s 内异步完成纯画面语义、按需单帧 OCR（仅空文本大图 20.1% 触发）、0–2 s WMS 浮窗压栈观测及设置页标签/可选包名品牌元数据核验，在最终确认弹窗处触发事中拦截或注入高显著度负向风险警示（行为经济学依据见 *Shen et al.* USENIX Sec'21）。
   - **阶段 B · 灰区拒权返回后 30 s 二轮升级**：仅当首次判定落入灰区且用户未授权退出设置返回应用时，维持 30 s 零 Layout 骨架观测，捕获无触摸驱动的自动重跳死循环并升级处置。

### 四阶段严格时序递进可分性（完全剥离「首次窗」与「二轮拒权窗」混算）

- **阶段 1（严格 `t0-ε` 跳前应用内纯画面，零外部元数据）**：覆盖主动恶意 **165/224（73.7%）**，含潜伏池 **168/241（69.7%）**；开源良性 **0/70**。

## 四、动态 GUI-Owl UTG 基准（已实测 40 款）的双重研究价值

伴生会话持续采集的动态真机/模拟器 UTG 数据集（[DYNAMIC_UTG_INDEX.md](gui_agent/dynamic_utg_dataset/DYNAMIC_UTG_INDEX.md)，截至 2026-11-25 已跑完 **40 款**：恶意 28 家族 / 25 可装、良性 12 品类 / 10 可装，落盘 **624 张截图、35 张连环画、277 份 Android XML 与 277 份鸿蒙 `uitest dumpLayout` JSON**）在整体研究体系中承担**双闭环支柱作用**：

1. **实测阶段关键发现**：

2. **双重核心定位（严格隔离开发集与盲测集，杜绝数据泄露）**：
   - **定位 ① · 前期典型攻击手法梳理底座（喂给 LLM 检测器的结构化先验）**：从开发集真实动态 UTG（含穿透加密壳样本与真实良性反例）中提炼去噪后的真实 UI 话术原型、高仿设置结构特征与良性高重叠豁免判据，构建传递给端/云 LLM 分类器的紧凑结构化知识库与判断 Rubric，替代存在偏差的静态代码推测；

## 五、70 款开源良性规律与「生态代表性偏差」警示

1. **开源良性 4 条共性合规特征**：① `70/70` 桌面名与系统服务名如实一致（允许品牌+功能后缀如 `RustDesk Input`）；② `0/70` 教唆忽视系统警告、拒权自动死循环或跳后异源压栈；③ `84.3% (59/70)` 提供免无障碍替代模式（ADB/Shizuku/Root/手动/仅观看）；④ 密码管理器 `KeePassDX` / `Keepass2Android` 新版已迁移至原生 `AutofillService`。
2. **三类高重叠误报风险与两项实测约束**：侧载受限设置教学（`24.3%`）、首启向导（`21.4%`）、隐私承诺（`38.6%`）不可单维判为恶意；动态/源码实测确认 `Screenshot Tile` 跳设置后弹普通底部 `Toast` 且描述首含 `U+200C`、`SuperFreezZ` 合法描述含 8 个段落换行。
3. **外部效度威胁（Benign Bias）**：当前 70 款良性 **100% 来自 F-Droid / IzzyOnDroid / GitHub 英文开源工具**（极简桌面占 18 款），尚未覆盖国内主流商业良性无障碍应用（远程协助、商业跳广告、自动化、适老化工具）。在补测 15–20 款国内商业良性集前，绝不可宣称全生态 0% 误报。

## 七、三源补盲扩充：动态实测与公开威胁情报新增 9 条行为模式 + 「首启不暴露」补全决策矩阵
