# 「中银会议 / 抖音会议 / N+会议 / 国密会议 / 云会议」同源灰产换壳远控族

- **案例编号**：`INTEL_CN_02` ｜ **地区与活跃期**：中国大陆（2024–2025）
- **诱导隐蔽度分级**：`L4 · 带外通话社工 + 伪会议/远控协同型`
- **为何首次动态运行容易遗漏**：加壳 + 会议号门控 + 授权后隐藏图标防卸载

## 一、伪装形式与接触通道
- **伪装外衣**：中银会议、抖音会议、N+会议、国密会议、云视听/云端会议（同套灰产远控源码批量换名换标，常见梆梆/爱加密/自定义壳 + `DexClassLoader` 动态加载）
- **带外接触通道**：冒充短视频平台、微信/支付宝「百万保障」或银行客服电话
- **应用内界面特征**：表面为会议号输入与一键入会界面；核心无障碍控屏载荷常经商业加壳或加密资产动态加载；取得无障碍后将自身图标变透明/隐藏，并在受害人进入应用管理尝试卸载时用 `GLOBAL_ACTION_HOME` / `GLOBAL_ACTION_BACK` 秒退设置页

## 二、典型诱骗话术
- 「您开通了每月扣费 800 元的「百万保障 / 直播保险」，不立即取消将连续扣款并上报征信」
- 「您手机操作太慢看不清，请按我说的在设置里打开「无障碍/辅助功能」方便专员远程代为关闭扣费通道」
- 「为了保护您的资金安全，需要通过官方指定「中银会议/抖音会议」进行屏幕共享与人脸核验」

## 三、攻击步骤与技术链路
- 1. 电话制造「自动扣费 / 影响征信」紧迫感并发送非商店下载链
- 2. 侧载安装仿冒银行/平台名称的会议木马，需输入骗子口述的会议号才建立 C2/WebSocket 连接
- 3. 诱导开启屏幕共享与无障碍权限，远程点击填表、读取验证码并在设置页实施防卸载回弹
- 4. 关键转账阶段制造黑屏/假死并诱导配合人脸识别完成盗刷（2025 年 3 月 65 岁徐女士「中银会议」案）

## 四、端侧可观测信号与鸿蒙防御映射
- 非官方来源 + 金融/政务/主流平台名称拼接「会议/客服/专员」
- 首启需输入会议号/连线 C2 才下发远控指令（解释单机离线首启不暴露原因）
- 无障碍授权后对「应用信息/无障碍设置」页面执行高频强行返回（防卸载秒退特征）
- **鸿蒙端侧防御要点**：结合应用市场签名校验、通话期屏幕共享+无障碍联动阻断、设置页防劫持保护
